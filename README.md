# simulador-nim-minimax

Para el desarrollo de este simulador, se integró el uso de Gemini como herramienta de programación agéntica en diferentes etapas del ciclo de vida del software.

Planificación e Interfaz: Se utilizaron prompts para definir una estructura visual clara utilizando Tailwind CSS, enfocada en resaltar los estados de los nodos (MAX/MIN) y diferenciar las ramas evaluadas de las podadas.

Implementación del Algoritmo: Se guio a la IA para construir la función recursiva Minimax, condicionando estrictamente el orden de exploración de los movimientos válidos para que coincidiera con el problema de Nim [1, 3] analizado teóricamente.

Validación y Despliegue: El código sugerido fue revisado para asegurar que la condición lógica de la poda Alfa-Beta fuera algorítmicamente correcta. Además, se utilizó asistencia para resolver conflictos de control de versiones en GitHub Desktop y realizar el despliegue público mediante GitHub Pages.

La asistencia de la IA actuó como facilitadora de la construcción técnica, manteniendo siempre el criterio analítico y la revisión de la correctitud del árbol del juego bajo mi responsabilidad.
